## Reflection
The easiest part of this assignment was doing the math calculations because I already knew how to add, multiply, and divide numbers. The hardest part was making sure the results showed up correctly on the webpage. I learned that the Date object can get the current date and that I can change how the date looks. I also learned that the Number object can turn strings into numbers and check if a value is a valid number or an integer. Lastly, I learned how to use getElementById() and innerHTML to display my JavaScript results on the webpage.
